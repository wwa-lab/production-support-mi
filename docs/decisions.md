- 用户于 2026-10-25 确认：事故处理仍在 ServiceNow / COSY 中，本平台同步记录、协助复盘和出报告；具体接口能力、源字段权威及同步频率尚未确认。
- 用户指定讨论仓库放在 GitHub `wwa-lab`。仓库默认设为私有；这不构成内部资料上传许可。
- 用户希望扩展为所有 FFer 可参与的 production support 日常知识库；现有 FF log 是值班人员收到生产 alert、消息或电话并处理问题后编写、再发给所有值班同事的处理日志。日志格式、保存与发送渠道尚待确认。
