## 先验证 5 个事故

样本合计应覆盖邮件链／转发引用、多版 PPT、图中信息与表格、讲者备注、邮件与 PPT 描述冲突、缺少原事故 ID 或 RCA 的情况。一个事故可覆盖多个场景。

为每个样本记录来源清单、人工确认的关键字段和事故归并关系。逐页检查实际 PPT，核对邮件正文与附件，记录提取遗漏、错误引用、错误归并和人工校正耗时。格式读取失败属于处理问题，不能据此认定事故没有相关信息。

通过后再扩至约 20–30 个事故，覆盖 AMH/HASE、不同年份和严重级别。样本用于验证方法及维护成本，不用于推断总体趋势或宣称全量覆盖。
